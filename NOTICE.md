# Сторонние компоненты

MIT в этом репозитории относится к собственным сценариям сборки, тестам,
overlay-службе и документации. Она не меняет условия сторонних проектов.

- [Keenetic SDK](https://github.com/keenetic/keenetic-sdk) загружается пользователем
  из закреплённой ревизии. Его файлы сохраняют собственные лицензии.
- Штатная прошивка получается с официального сервера Keenetic либо предоставляется
  пользователем. Она содержит закрытые компоненты и не распространяется в этом
  репозитории. См. [условия Keenetic](https://keenetic.com/en/legal).
- [Xray-core](https://github.com/XTLS/Xray-core/tree/v26.11.9) загружается из
  официального выпуска; его [MPL 2.0](https://github.com/XTLS/Xray-core/blob/v26.11.9/LICENSE)
  включается в персональный образ. Исходники Xray не модифицируются.
- [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains) и
  [Loyalsoldier/geoip](https://github.com/Loyalsoldier/geoip) — источники списков
  маршрутизации. Их данные загружаются отдельно по закреплённым ревизиям и хешам;
  исходные списки не включены в этот репозиторий.
- [dissect.squashfs](https://github.com/fox-it/dissect.squashfs) используется
  локально для проверки файловой системы; устанавливается отдельно через pip.

Сборка не предоставляет права на публичное распространение чужих компонентов.
Готовый образ дополнительно содержит личный профиль VLESS: его нельзя считать
общедоступным установщиком или размещать в публичном Release.
