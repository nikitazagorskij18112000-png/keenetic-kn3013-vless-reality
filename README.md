# VLESS + Reality для Keenetic Speedster KN-3013

Комплект локальной сборки персональной прошивки KeeneticOS с Xray. Запустите сборку в Ubuntu, введите свою ссылку `vless://` и получите образ для своего роутера. Данные подключения обрабатываются на вашем компьютере и встраиваются в результат.

**Экспериментальный проект для KN-3013 EAEU.** Основа прошивки — KeeneticOS 5.1.8 с Xray 26.11.9 — проверена на моём Keenetic Speedster KN-3013 EAEU: VLESS + Reality работает, российские сайты идут напрямую, остальной трафик — через VPN.

Автоматический сборщик создан на основе этой рабочей персональной сборки. Он прошёл 64 автоматических теста и полную сборку с тестовым профилем из чистого SDK с кэшем архивов зависимостей. **Образ, созданный автоматическим сборщиком, пока отдельно на физическом роутере не проверялся.** Подробности — в [VALIDATION.md](docs/VALIDATION.md).

## Что нужно

- **Keenetic Speedster KN-3013 EAEU**. Другие модели и аппаратные варианты не подтверждены.
- Рабочий сервер и клиентская ссылка **VLESS + Reality по TCP/RAW**. Поддерживаются пустой `flow`, `xtls-rprx-vision` и `xtls-rprx-vision-udp443`. Другие транспорты и дополнительные неподдерживаемые параметры отклоняются.
- **Ubuntu 24.04 x86-64** или **WSL 2 с Ubuntu 24.04** в Windows. Сборка выполняется обычным пользователем Linux, не `root`.
- Интернет для получения официальной прошивки, SDK, Xray и исходников зависимостей. Для режима `ru-direct` также загружаются списки маршрутизации.
- Место на Linux-диске: рекомендуется не менее **15 ГБ**; для сборки рекомендуется **4 ГБ ОЗУ** или больше.

Сборка идёт в Linux-файловой системе. Не размещайте рабочий каталог в `/mnt/c`, `/mnt/d` или общей папке с NTFS. Путь рабочей папки должен состоять из латинских букв, цифр, `/`, `.`, `_` и `-`, без пробелов.

## Быстрый запуск

Если WSL ещё не установлен, установите Ubuntu 24.04 командой `wsl --install -d Ubuntu-24.04` в PowerShell администратора, завершите предложенную Windows настройку и откройте Ubuntu. Создайте обычного пользователя Linux.

Следующие команды выполняются **в терминале Ubuntu**:

```bash
sudo apt update
sudo apt install -y git
cd ~
git clone https://github.com/nikitazagorskij18112000-png/keenetic-kn3013-vless-reality.git
cd keenetic-kn3013-vless-reality
sudo bash scripts/install-deps.sh
bash build.sh
```

Когда появится запрос, вставьте свою VLESS-ссылку и нажмите Enter. Ввод скрыт: отсутствие текста на экране нормально. Не дописывайте ссылку к команде запуска — так она может попасть в историю терминала и список процессов.

По умолчанию выбирается режим **`ru-direct`**: российские домены и сети напрямую, остальное через VPN. До успешного завершения проверок не используйте промежуточные образы SDK.

## Результат

Сборщик выведет путь к новой папке:

```text
~/kn3013-builds/<уникальная-папка>/dist/
├── KN-3013_5.1.8_Xray-26.11.9_PERSONAL.bin
├── SHA256SUMS
└── verification.json
```

`verification.json` содержит результаты автоматических проверок. Прошивка и рабочий каталог содержат ваши данные подключения; храните их локально и не прикладывайте к Issues или Releases. Журналы остаются в рабочей папке. Перед передачей даже диагностических файлов проверьте их содержимое.

В Linux рабочая папка и файлы с профилем ограничиваются правами доступа. При копировании в Windows эти права могут не сохраниться: доступ к файлам на NTFS определяется настройками Windows.

**Сборщик не прошивает роутер автоматически и не подключается к указанному VPN-серверу.** После сборки следуйте [инструкции установки и настройки](docs/INSTALL.md). В ней описаны Recovery, прокси-подключение, DNS, политики домашней сети и проверка с телефона.

## Параметры запуска

| Параметр | Для чего |
|---|---|
| `--routing ru-direct` | Российские исключения напрямую; режим по умолчанию |
| `--routing all-vpn` | Всё, направленное политикой в Xray, через VPN |
| `--stock /путь/к/прошивке.bin` | Использовать локальную официальную прошивку вместо скачивания |
| `--link-file /путь/к/ссылке.txt` | Прочитать VLESS-ссылку из отдельного локального файла |
| `--work-dir /home/user/kn3013-new-build` | Выбрать **новый, ещё не существующий** рабочий каталог |
| `--jobs 2` | Число параллельных задач компилятора; по умолчанию 2 |
| `--sdk-download-cache /путь/к/dl` | Скопировать ранее загруженные архивы зависимостей SDK для ускорения сборки |
| `--xray-archive /путь/к/Xray-linux-mips32le.zip` | Использовать локальный архив закреплённого Xray с проверкой SHA-256 |
| `--routing-cache /путь/к/спискам` | Использовать локальные файлы списков маршрутизации вместо их скачивания |

Пример для всего трафика через VPN:

```bash
bash build.sh --routing all-vpn
```

Пример с профилем в отдельном файле:

```bash
chmod 600 ~/private-vless.txt
bash build.sh --link-file ~/private-vless.txt
```

Создайте этот файл локальным текстовым редактором и вставьте в него только ссылку. Не храните его в репозитории. `--stock` принимает только закреплённую официальную **5.1.8** с ожидаемым хешем; произвольная резервная копия другой версии не подойдёт.

Кэш SDK предназначен только для архивов зависимостей, полученных из доверенных источников. Не указывайте в качестве кэша каталог старого SDK целиком, `files/`, `build_dir/`, персональные конфигурации или готовые образы. При ошибке создайте новую рабочую папку; сборщик не объединяет её с прежней.

Локальные архивы и списки сокращают загрузки, но сами по себе не гарантируют полностью автономную сборку: SDK может потребовать другие исходники. Формат и зафиксированные контрольные суммы входных файлов определены в исходниках комплекта.

| Компонент | Версия |
|---|---|
| KeeneticOS | `5.1.8` / `5.01.C.8.0-2` |
| Keenetic SDK | `5c74fc4d907383c91e8d6af3f5d67501f7acb171` |

В образ входят Xray, профиль, служба запуска с ожиданием корректного времени и правила выбранного режима. Для размещения Xray убраны IntelliQoS/NTCE/PACE2 и языки интерфейса, кроме русского и английского. Загрузочные компоненты и разметка флеш-памяти не меняются.

По умолчанию основа скачивается из [официального архива Keenetic](https://osvault.keenetic.net/KN-3013/5.01/KN-3013_stable_5.1.8_5.01.C.8.0-2.bin). Ожидаемый SHA-256:

```text
d3108ef3081afb118c7d3d4bcd8512dc27976c7d909a6f185452ec0f4d6663e0
```

Это локально зафиксированный отпечаток ранее полученного официального файла, а не независимая цифровая подпись производителя. Не отключайте проверку хеша при несовпадении.

## Маршрутизация и обслуживание

- `ru-direct` использует российские доменные суффиксы, российские IP-сети и исключения для зарубежных сервисов. Это приближённая классификация: страна сервиса не всегда совпадает с доменом или адресом CDN. Подробности — в конфигурации и [инструкции](docs/INSTALL.md).
- Ссылка и списки встраиваются в прошивку. **Смена сервера, клиента или правил требует новой сборки.** Формы ввода VLESS в штатной админке этот комплект не добавляет.
- До запуска Xray роутеру нужны обычное подключение провайдера, DNS и синхронизация времени. Подключённые устройства затем направляются в отдельную политику с локальным SOCKS5.
- Обычное обновление KeeneticOS или изменение компонентов может заменить сборку и удалить Xray. Автоматическое обновление отключается при установке; дальнейшие обновления следует готовить и проверять вручную.
- Работа IPv6 через VPN, отдельный выход UDP и поведение при отказе WAN не подтверждены для новой сборки. Комплект не обещает отсутствие утечек во всех сценариях.
